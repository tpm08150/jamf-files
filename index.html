Install as a desktop app
  1. Chrome / Edge: open this page → the install icon at the right of the address bar (or menu → Cast, save and share → Install page as app) → Install. You get a dock/taskbar icon that opens in its own window.
  2. Safari (macOS 14+): File → Add to Dock.
  3. iPad / iPhone: Share → Add to Home Screen.
